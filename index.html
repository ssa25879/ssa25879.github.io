이미지 검색 앱

UsingAI-ImageSearchApp · Unity 기반 앱 개발

Unity 6C# UI ToolkitUniTask Pixabay API

프로젝트 개요

검색어로 이미지를 찾고 결과와 썸네일을 확인할 수 있는 세로형 앱입니다. UI Toolkit으로 화면을 구성하고, 검색과 썸네일 로딩을 별도의 Repository 인터페이스로 연결했습니다.

실행 화면

프로젝트 개발 및 수행 내용

1. 검색 화면과 상태 처리
  • 검색 중, 검색 결과, 빈 결과, 오류 상태를 구분해 화면에 표시했습니다.
  • 썸네일을 비동기로 로딩하고, 개별 이미지 로딩 실패는 해당 카드의 대체 표시로 처리했습니다.
2. 레이어 분리와 API 연결
  • Presentation·Domain·Data·Core와 Composition Root로 역할을 나누고, 화면이 API 구현에 직접 의존하지 않도록 구성했습니다.
  • Pixabay 검색과 썸네일 HTTP 요청을 Repository 인터페이스에 연결하고, 네트워크 오류를 화면에서 사용할 결과 타입으로 변환했습니다.
  • 실제 API와 Mock 구현을 교체할 수 있게 구성해 성공·빈 결과·연결 실패·서버 오류 흐름을 확인할 수 있도록 했습니다.
3. 요청 취소와 응답 순서 관리
  • 새 검색이 시작되면 이전 검색과 썸네일 작업을 취소하고, 요청 세대를 비교해 오래된 응답이 최신 결과를 덮어쓰지 않도록 했습니다.
  • 화면 종료 시 진행 중인 작업을 취소하고, 검색 결과에 사용한 텍스처의 수명을 관리했습니다.

기술적 포인트

검색 결과가 없는 경우와 네트워크 오류를 구분하고, 검색 요청과 이미지 로딩의 실패 범위를 나눴습니다. 실제 API 연동은 Editor 개발 환경에서 사용하며, 모바일 빌드는 현재 Mock 구현을 사용하는 단계입니다.

  • 무기·탄약 정보와 캐릭터 머리 위 재장전 알림·진행 바를 표시했습니다.
  • 카메라 방향을 기준으로 주변 적을 표시하고, 탐지 범위 밖의 위협은 가장자리 화살표로 안내했습니다.
  • 강화 적의 미니맵 표시를 색상과 크기로 구분하고, 마커를 재사용하도록 구성했습니다.
4. 재사용 가능한 설정 모듈
  • 볼륨·전체 화면·해상도·그래픽 품질·VSync 설정을 게임 코드와 분리한 GameSettingsKit 모듈로 구성했습니다.
  • PlayerPrefs로 설정을 저장하고, AudioMixer를 통해 음악과 효과음 볼륨을 분리했습니다.

기술적 포인트

사격 판정과 총구의 시각적 연출을 분리하고, 카메라 방향과 미니맵 좌표 기준을 일치시켰습니다. 전투 중 필요한 상태를 HUD로 전달하면서, 설정 기능은 다른 Unity 프로젝트에서도 사용할 수 있도록 분리했습니다.

Android 조작

  • 가상 스틱 이동과 자동 조준 사격 또는 트윈 스틱 직접 조준 방식을 선택할 수 있습니다.
  • 터치 화면에서 재장전과 무기 교체를 조작하고, 볼륨·그래픽 품질을 설정할 수 있습니다.

프로젝트 개요

프로젝트 개발 및 수행 내용

1. 근무 패턴 기반 달력 계산
  • 주간·오후·야간·당직·비번·휴무 패턴을 기준일과 함께 등록해 월간 근무표를 계산합니다.
  • 오늘·내일 근무 요약과 날짜별 메모, 공휴일을 달력에서 확인할 수 있습니다.
2. 사용자별 근무표 설정
  • 근무 유형의 이름·약어·색을 편집하고, 변경을 오늘부터 또는 전체 기간에 적용할 수 있습니다.
  • 이전 근무 패턴을 불러와 교대 순서를 다시 설정할 수 있습니다.
3. 근무표 내보내기
  • 보고 있는 달의 근무표를 PNG 이미지나 캘린더 파일(.ics)로 내보냅니다.
  • v1.3에서는 캘린더 파일에 근무 전날 알림을 추가하는 기능과 같은 달 재내보내기 오류를 개선했습니다.

웹 버전으로 확장

토스 미니앱을 바탕으로 브라우저에서 사용할 수 있는 웹 버전을 만들었습니다. 자체 UI와 localStorage로 전환하고, 백업·복원과 PWA 설치·오프라인 실행을 지원합니다. 두 버전의 데이터는 자동으로 공유되지 않습니다.
